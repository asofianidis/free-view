Keyboard shortcuts

1 … 9, 0Open dial 1–10 of the current group (hold Shift for a background tab)
← →Previous / next group
/Focus the search box
NAdd a dial
GAdd a group
BToggle the sidebar
LLock (when a password is set)
Ctrl/Middle clickOpen dial in a background tab
Shift clickOpen dial in a new window
Alt+Shift+AAdd the current page from any tab
Alt+Shift+DOpen the add-dial popup

Browser-wide shortcuts can be changed at chrome://extensions/shortcuts.
